# today-s_meal

# 학교급식 비교 분석 대시보드

NEIS(나이스) 급식식단정보 Open API를 사용해 여러 학교의 급식을 비교 분석하는 Streamlit 앱입니다.

## 실행 방법

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 사용 방법

1. 사이드바에 NEIS API 인증키를 입력합니다.
   - 발급: https://open.neis.go.kr → "인증키 신청"
   - 인증키가 없어도 실행은 되지만 학교당 5건(sample key)만 조회됩니다.
2. 분석 기간(시작일/종료일), 식사 구분(조식/중식/석식)을 선택합니다.
3. 비교할 학교를 선택합니다. **당곡고등학교**가 기본으로 선택되어 있으며,
   수도여자고등학교, 성남고등학교, 영락고등학교를 추가로 선택해 비교할 수 있습니다.
   - 동명 학교가 여러 지역에 있을 경우 후보 목록에서 정확한 학교를 선택하는 라디오 버튼이 나타납니다.
4. 4개의 탭에서 분석 결과를 확인합니다.
   - **김치 등장 분석**: 기간 내 김치 메뉴가 등장한 일수/비율, 날짜별 타임라인
   - **평균 단백질 분석**: 학교별 평균/최대/최소 단백질(g), 날짜별 추이
   - **디저트 요일 분석**: 요일별 디저트 등장 횟수, 학교별 디저트가 가장 자주 나오는 요일
   - **원본 데이터**: 파싱된 전체 데이터 확인 및 CSV 다운로드

## 커스터마이징

- `DEFAULT_SCHOOLS` / `SEARCH_ALIASES`: 비교 대상 학교 목록 및 검색 별칭을 수정할 수 있습니다.
- `DESSERT_KEYWORDS`: 디저트로 판별할 메뉴 키워드 목록입니다. 학교 메뉴 특성에 맞게 자유롭게 추가/수정하세요.

## 참고

- API 명세: https://open.neis.go.kr/hub/mealServiceDietInfo (급식), https://open.neis.go.kr/hub/schoolInfo (학교기본정보)
- 요리명(DDISH_NM)에 표시된 숫자는 알레르기 유발 식재료 코드입니다(예: 1.난류, 5.대두 등). 이 앱은 해당 숫자를 파싱해서 제거한 순수 메뉴명만 분석에 사용합니다.
- 영양정보(NTR_INFO)는 학교/급식업체에 따라 항목 구성이 다를 수 있으며, '단백질'이라는 문자열이 포함된 항목을 자동으로 찾아 사용합니다.
